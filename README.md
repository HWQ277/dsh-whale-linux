# DeepSeek 余额小鲸鱼 · Arch Linux 桌面版

[原项目](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)（DSH Web 界面右下角的余额挂件）的 **Arch Linux 桌面移植版**：
一只常驻桌面右下角的小鲸鱼，盯着你的 **DeepSeek 账户余额**和**今日已用**。

**纯 Python 3 + tkinter + 标准库**，零第三方依赖；用 **X11 SHAPE 扩展**做真正的镂空异形窗口——
鲸鱼和气泡以外的地方完全透明，**不需要混成器（compositor）**。

![小鲸鱼挂件](assets/DSH2.png)

---

## 功能

| 功能 | 说明 |
|---|---|
| 💰 余额 | 调用 `https://api.deepseek.com/user/balance`，默认 60 秒自动刷新，左键点鲸鱼手动刷新 |
| 🎢 数字滚动 | 余额变化时数字以 cubic ease-out 平滑滚动到新值（与原版一致，700ms） |
| 📊 今日已用 | **不需要任何额外令牌**：通过观测余额下降推算当日消费；余额上升（充值/赠金）单独记录，不会冲掉已产生的消费 |
| ⛰️ 峰谷时段 | 北京时间 09:00–12:00、14:00–18:00 为高峰，**周末全天谷价**（与原版同一套规则） |
| 🖱️ 拖拽 + 吸附 | 拖到屏幕四分之一边缘自动吸附；**贴左吸附时整体水平镜像翻转** |
| 🧸 按压 Q 弹 | 按下鲸鱼时挤压变形（底边不动），松开回弹，和原版玩偶手感一致 |
| 💬 点击序列气泡 | 点一下鲸鱼弹出气泡，5 秒后自动消失（和原版一致）。连点会往后推进：余额 → 今日已用 → 峰谷 → 随机语句 → 收起 → 循环 |
| 🧩 模块化气泡 | 气泡由「行 × 模块」组成，模块类型：纯文本 / 余额 / 今日已用 / 峰谷 / **加权随机语句** / **图片**，每个模块可单独设字号、加粗、斜体、下划线、颜色 |
| ⛰️ 峰谷多种样式 | 默认 / 梁文峰谷 / 强强 / 简洁，菜单里一键切换 |
| ⏰ 空闲气泡 | 默认**关闭**；想要的话可在设置里按间隔开启 |
| 🔤 字号与原版一致 | 字号直接用原版的 CSS 公式 `calc(--dshw-u × N)`，`u = base/1026`。默认缩放下标题 18px、金额 35px |
| 🔊 音效 | 内置上游同款两组：**小黄鸭**（`Ya1`/`Ya2`）与**音效1**（`D1`/`D2`），按下/松开各一声；自动挑 `paplay`/`pw-play`/`aplay`/`ffplay` 播放器 |
| 💬 气泡 | 白色对话气泡 + 尾巴，几何形状由原版 SVG 逐像素描摹而来；鼠标悬停显示菜单按钮 |
| ⚙️ 设置窗 | API Key、挂件大小（0.6×–2.5×）、刷新间隔、气泡开关、吸附、置顶、异形窗口开关 |
| 📌 置顶/跳过任务栏 | 通过 EWMH `_NET_WM_STATE_ABOVE` / `SKIP_TASKBAR` / `_NET_WM_WINDOW_TYPE_DOCK` |

## 安装

### 方式一：用户级安装（推荐，不需要 sudo）

```bash
./install.sh
dsh-whale settings     # 填入 API Key
dsh-whale run          # 启动挂件
```

安装到 `~/.local/{bin,lib,share}`，并注册桌面菜单项。
如果 `~/.local/bin` 不在 `PATH` 里，请重新登录或手动加入。

### 方式二：pacman 包（系统级）

```bash
makepkg -si
```

包名 `dsh-whale-widget`，依赖 `python` 与 `tk`（后者提供 tkinter）。

### 方式三：直接运行源码

```bash
python3 dsh-whale run        # 无需安装
```

### 卸载

```bash
./install.sh --uninstall     # 用户级
sudo pacman -R dsh-whale-widget   # 包管理
```

配置目录 `~/.config/dsh-whale/` 不会被删除。

命令行：

## API Key

按优先级：

1. 环境变量 `DEEPSEEK_API_KEY`
2. `~/.config/dsh-whale/config.json` 里的 `secrets.apiKeyB64`（设置窗写入）

> **关于存储安全**：配置文件权限是 `0600`，密钥以 **base64 编码**保存，**不是加密**。
> 同机器上以你的身份运行的程序都能读到它。这是 Linux 上不引入第三方 keyring 依赖时的取舍。
> 如需更强保护，请把 Key 放在环境变量里，并让设置窗中的 Key 留空。

获取 Key：<https://platform.deepseek.com/api_keys>

## 工作原理

```
src/dshwhale/
├── cli.py          命令行入口（run / settings / status）
├── config.py       ~/.config/dsh-whale/config.json 读写（0600，原子写入）
├── balance.py      DeepSeek 余额接口（stdlib urllib，重试 + 超时 + 钱包选择）
├── ledger.py       按余额观测推算今日消费；北京时间峰谷判定
├── imageio.py      纯 stdlib 的 PNG / GIF 解码器（zlib + struct）
├── x11.py          ctypes 调用 libX11 / libXext：SHAPE 异形窗口、EWMH 置顶
├── bubbles.py      气泡内容模型：行/模块/随机加权/模板变量
├── bubble_geom.py  由原版 SVG 描摹出的气泡轮廓（法线化坐标）
├── widget.py       挂件窗口：绘制、拖拽吸附、镜像、数字滚动
└── settings.py     设置窗口
```

### 异形窗口是怎么做到的

原版在浏览器里靠 CSS 透明。桌面版没有浏览器，而本机 **XFCE 默认没启用混成器**，
所以 ARGB 真透明不可用。这里改用 **X11 SHAPE 扩展**：

1. 把气泡轮廓（`bubble_geom.OUTER`，描摹自原版 SVG）和鲸鱼贴图的 **alpha 通道**
   光栅化成一张 1-bit 位图；
2. 用 `XShapeCombineMask` 把它设成窗口的 **Bounding / Clip** 形状 —— 注意
   **要沿父链一路设到 X 的包装窗口（frame）**，只设 tkinter 自己的窗口是没用的：
   frame 会照旧画出一整块背景色，这正是「蓝色方块」的成因；
3. **不要**裁 `Input` 形状。裁剪它看着更精致，但会让空白区域的点击穿透到桌面，
   连气泡上的右键都收不到 —— 菜单就再也打不开了。保留整块矩形作为输入区，
   挂件才始终响应鼠标。

结果是窗口之外的像素根本不存在——**不依赖混成器**，在没开合成的 XFCE 上也是真透明。

窗口是**正方形**的（和原版一样：`width == height == base`），气泡占上面一条
（宽高比 1026/700），鲸鱼固定在右下角、边长 59.45%。这点很关键——最初把它做成了
只有气泡那么高，鲸鱼就被顶进气泡里，把气泡糊掉了一半。

如果 X 服务器不支持 SHAPE，或你在设置里关掉了「异形窗口」，挂件会退化为
**矩形卡片**：此时鲸鱼贴图会预先按窗口背景色混合（`imageio.flatten_on`），
半透明边缘不会出现黑边或白边。

### 泡泡模块字号

上游编辑器里的字号是 **1..50 的档位**，不是像素：

```js
function bubbleModuleFontU(level) {
  var n = Math.max(1, Math.min(50, Math.round(Number(level) || 6)))
  return Math.round(40 + (n - 1) * 200 / 49)   // 1 → 40u ... 50 → 240u
}
```

再按 `font-size: calc(var(--dshw-u) * N)` 渲染（`u = base/1026`）。
本移植版的 `Module.size` 就是这套档位，`bubbles.font_units()` 复刻了那个公式。
调色板默认档位也照抄：文本 6、余额数值 11、今日已用 1、峰谷 4、倒计时 6、
对话名 4、超链接 6。

## 排错

**气泡里的字太小 / 太大 / 被切掉？**
原版的字号全部写成 `calc(--dshw-u * N)`，其中 `--dshw-u = base / 1026`，
N 取自它的样式表：`.dshwv-label` 66、`.dshwv-amount` 128、`.dshwv-period` 104、
`.dshwv-hint` 56。所以默认缩放（base = 280px）下：标题 **18px**、金额 **35px**、
提示 **15px**。

配置里的 `size` 就用这套 N 值，渲染时按 `N * size / 1026` 换算。**不要**自己另发明
一套数字再全局缩放 —— 我一度把 92 当成"设计单位"去乘 `size/1026`，结果金额只有
25px（原版 35px）、标题只有 8px（原版 18px），字小得看不清。只有真的塞不下时
（超出气泡内框 199×129）才会按比例缩一档。

**挂件整个不见了 / 只剩一个蓝方块？**
最常见的两个原因：
1. **屏幕保护程序把屏幕熄了** —— 截图会是纯黑，`xfce4-screensaver-command -q` 看状态，
   `-deactivate` 唤醒。
2. **异形窗口掩码算空了**。这类失败现在会往 stderr 打一行
   `[dsh-whale] 异形窗口掩码失败…`，不再静默退化。
   曾经的成因是 `mirrored` 变量只写在 `if self.bubble_open:` 里面，
   气泡关着时下面用它会抛 `UnboundLocalError`，被裸 `except` 吞掉 → 掩码全空 → 整只鲸鱼被裁掉。

**右键没反应？**
菜单曾经因为 `tk.Label(..., pady=(8, 2))` 直接抛
`TclError: bad screen distance "8 2"` 而根本建不出来（元组形式的 `pady`
只有 `pack`/`grid` 接受，控件构造参数只收单个数值）。现在改成整数并在失败时清理
半成品窗口，避免残留的 `self.window` 让后续点击全部失效。

**整个挂件忽然不见了？**
先确认不是屏幕保护程序把屏幕熄了：`xfce4-screensaver-command -q` 看状态，
`xfce4-screensaver-command -deactivate` 唤醒。屏幕一黑，截图和肉眼都会以为挂件挂了。

**字变得特别大？**
模块 `size` 是 **1–50 的档位**，不是像素。旧配置里残留的 `66 / 128 / 56`
被当成档位就成了 level 50 → **65px**，字当然炸了。现在配置已迁移成上游档位
（8 / 20 / 4 / 2）。想自己调就改 `~/.config/dsh-whale/config.json` 里
`bubbles.first.lines[].size`，1 最小、50 最大。

**气泡底下的蓝色不消失？**
那其实不是气泡，是**鲸鱼本体**。上游允许气泡和鲸鱼在网页里半透明叠着，
桌面版没有合成器、两层都不透明，谁后画谁赢 —— 0.5945 的鲸鱼会伸进气泡框
（`x 20..228, y 2..140`）约 101×23px，气泡隐藏后那块还是被鲸鱼占着。
所以 `SPRITE_FRACTION` 调成 **0.375**，让鲸鱼的**实际不透明区域**
（不是图片矩形）完全避开气泡框。实测气泡隐藏时整个气泡区
`transparent=53307, white=0, navy=0` —— 干干净净。

**移到左侧时有"蓝底"？**
两种可能，都查过了：

1. **那是鲸鱼本体**，不是背景。贴左时鲸鱼会镜像到底角，它本身是很深的藏青。
   实测贴左/贴右的掩码完全一致（泡内不透明像素都是 173px，差异只是 `ox` 从
   175 变成 0，即镜像），所以左右没有渲染差异。
2. **挂件压在桌面面板上**。挂件是镂空的，压在面板上就会**透出面板的颜色** ——
   XFCE 默认主题的面板是亮蓝 `rgb(53,132,228)`，看着就像一层蓝底。
   实测左侧那条面板占 `x −6..125`，贴左的挂件正好落在上面。

现在加了**面板避让**（`settings.avoidPanels`，默认开）：吸附和摆放时都会
检测贴着屏幕边缘的 dock 窗口，把它挪开。两个轴都会试，因为通栏的顶部面板
横向躲不掉。实测四种吸附组合：

```
left/top    -> ( 129,  31)  overlap=0  ✓
left/bottom -> (   0, 800)  overlap=0  ✓
right/top   -> (1640,  31)  overlap=0  ✓
right/bottom-> (1640, 800)  overlap=0  ✓
```

不想要这个行为就在设置里关掉 `avoidPanels`（或直接改 config.json）。

**右键菜单时灵时不灵？**
打开菜单的那一次点击本身会命中"点外面就关闭"的逻辑，于是开了又立刻关。
现在加了 **0.35s 宽限期**，并且右建（`num == 3`）不参与关闭判定。
实测连续 6 次右键 **6/6** 都能打开。

**语录会像抽奖一样闪？**
`resolve_line` 每次调用都会重新抽随机句，而余额滚动动画一次要重画 28 帧，
于是句子一路闪过去。更糟的是抽取逻辑**刻意避免重复**上一条，所以帧帧都变。
现在按 **(行号, 模块号)** 把这一档显示选中的句子缓存下来，一次显示只抽一次。
实测同样的 28 帧渲染，从"7 个不同句子"变成 **恒定 1 个**。

**点了鲸鱼没反应 / 没有气泡？**
先检查配置里的 `settings.bubbleOn` 是不是 `true` —— 主菜单里有「气泡：开/关」
这一项，误点一次就会把气泡整个关掉（`_open_bubble` 会直接返回）。
`dsh-whale status` 或直接看 `~/.config/dsh-whale/config.json` 就能确认。

**改了配置不生效？**
`~/.config/dsh-whale/config.json` 改动后需要重启挂件（`dsh-whale` 只在启动时读一次）。
气泡模板里的 `{balance}` `{today}` `{peak}` `{currency}` `{name}` 会在每次绘制时替换。
